# 🛡️ AdBlock Max (Cyberpunk Edition)

تطبيق أندرويد متكامل واحترافي للحماية، حظر الإعلانات، إدارة الجدار الناري، وفحص الشبكات، مبني بلغة **Kotlin** بتصميم **Cyberpunk Dark & Neon Cyan**.

---

## ✨ المميزات الرئيسية (56 ميزة عبر 6 مراحل)

### 1. محرك تصفية الـ VPN والـ DNS المحلي (Local DNS Split-Routing)
- تصفية فورية وحجب النطاقات الإعلانية الخبيثة وشبكات التتبع.
- معمارية **Direct DNS Split-Routing** فائقة السرعة بدون أي بطء أو استهلاك غير ضروري للبطارية.
- منع تسريب IPv4 / IPv6 Leak Protection.
- 5 أوضاع تصفية جاهزة (قياسي، متشدد، أمان عائلي، ألعاب منخفض البينج، وDNS مخصص).
- ميزة التبديل الذكي الصامت عند انقطاع السيرفر (Silent Auto-Failover).

### 2. الاختصارات السريعة والأتمتة الذكية
- **Quick Settings TileService:** زر في لوحة إعدادات النظام السريعة لتشغيل/إيقاف الحماية.
- **Home Screen Widget (1x1 & 2x1):** ودجت أنيق للشاشة الرئيسية.
- **App Shortcuts:** اختصارات الضغط المطول على أيقونة التطبيق (تبديل الوضع، كتم الحظر 5 دقائق).
- **Automation Manager:** التشغيل التلقائي عند بدء تشغيل الجهاز، عند الاتصال بالواي فاي، ومؤقت النوم (Sleep Timer).

### 3. الجدار الناري وإدارة التطبيقات (Per-App Firewall)
- عزل وحظر الإنترنت عن أي تطبيق محدد (واي فاي / بيانات الهاتف).
- كوتة الاستهلاك اليومي للبيانات مع تنبيهات ذكية.
- قائمة الاستثناءات البيضاء (Bypass Whitelist).

### 4. الرادار الحي وسجل حركة المرور (Live DNS Radar)
- مراقبة حية لطلبات النطاقات مع تحديد التطبيق المتصل.
- حظر النطاقات يدويًا بضغطة زر وتصدير السجلات بصيغة CSV / JSON.
- فلاتر جغرافية وتصنيف النطاقات حسب خطورتها.

### 5. أدوات فحص الشبكة ومراقب الألعاب (Network & Router Suite)
- فحص المتصلين على الراوتر (Wi-Fi Intruder Scanner).
- فحص المنافذ المفتوحة (Port Scanner) واختبار سرعة واستقرار الاتصال (Ping & Latency Tester).
- نافذة عائمة لمراقبة البينج واستهلاك البيانات أثناء الألعاب.

### 6. المتصفح المانع للإعلانات والخصوصية الفائقة
- متصفح ويب مدمج فائق السرعة خالي من الإعلانات تماماً مع تخطي إعلانات الفيديو تلقائياً.
- منظف روابط التتبع (URL Tracking Stripper).
- قفل التطبيق برمز PIN الأبوي.
- نظام التحديث التلقائي المباشر من GitHub Releases.
